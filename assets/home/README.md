# Welcome header artwork

The illustrated school scrapbook background is an image-generation edit based on the supplied visual reference. It keeps the reference's blue sky, sunflower palette, Polaroid imagery and stationery composition, with the lettering and navigation recreated as live HTML. It is a visual reconstruction, not a byte-for-byte copy or documentary photograph of the school.

`title-brush.ttf` is Knewave Regular from the official Google Fonts repository (`ofl/knewave`), distributed under the accompanying SIL Open Font License. Existing site body and handwriting fonts are retained.
