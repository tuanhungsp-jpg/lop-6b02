# Shared typefaces

All fonts are hosted locally and include Vietnamese glyphs.

- Baloo 2 variable (400–800): rounded section and display headings.
- Be Vietnam Pro Regular, SemiBold and Bold: body copy, navigation and controls.

Downloaded from the official Google Fonts repository, `ofl/baloo2` and `ofl/bevietnampro`. Both are distributed under the included SIL Open Font License notices.
