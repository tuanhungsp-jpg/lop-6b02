# Diary demo artwork

`garden.webp` and `demo-sheet.webp` are generated illustrations for the diary interface. The eight fictional school-life photos in the demo sheet are not real photographs of class6B02. Each demo entry is visibly labeled; the two video entries are poster demonstrations and have no playable video.

The contact sheet has two columns and four rows, referenced with CSS background positions to avoid eight duplicate downloads. Real images and videos can be previewed using the add-memory dialog, which stores files only in IndexedDB on the current browser. Nothing is uploaded to a remote service. Clearing that browser's site data removes local memories; keep original files separately.
