# Yearbook artwork

- `scene.webp`, `paper.webp` and `sunflowers.webp` are original generated artwork for this website, encoded as WebP for delivery. The classroom is a decorative illustration, not a photograph of the school's actual classroom.
- `handwriting.ttf`: Caveat, from the official Google Fonts repository.
- `title.ttf`: Dancing Script, from the official Google Fonts repository.
- `body.ttf`: Be Vietnam Pro Regular, from the official Google Fonts repository.

Font license notices are included next to the fonts. Yearbook member profiles are illustrative until the class supplies its real roster and portraits; the class photo remains labeled as an illustration.
